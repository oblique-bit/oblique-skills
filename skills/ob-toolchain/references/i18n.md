# `i18n` Schematic

Source: Directus content version `oui-4570`, Toolchain page `i18n`.

Configure project internationalization with:

```shell
npx @angular/cli@latest generate @oblique/toolchain:i18n
```

For each whitespace-separated locale, the schematic registers Angular locale
data, configures Oblique's language control, sets `LOCALE_ID` to the first
locale unless one already exists, configures translation defaults, and adds
`@ngx-translate/core`.

The default locales are `de-CH fr-CH it-CH`. The `add-oblique` schematic calls
this schematic automatically.
