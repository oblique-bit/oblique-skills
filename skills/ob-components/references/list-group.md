# List group

## Purpose

The List Group component improves scanability by grouping items (text and images) in a structured sequence. The items can accommodate interactive elements like links, checkboxes, radio buttons, etc.

## Usage rules

Use it:
- Use it to sort content in a logical way: alphabetical, numerical, chronological, or by user preference.
- Use it to provide more context to checkboxes or radio buttons.
- Use consistent length and the language style for each of the list elements.
- Use it to enrich a simple text list with images or icons.
- Use it with supporting text to provide more context to each element if needed.

Do not use it:
- Do not use it when there is very little data to show. The UI can look empty.
- Do not use it when you need to highlight specific content over other elements.

## How to use

This is only a redesign of the Angular Material "List" component.

The API definition is available on the Angular Material site: [List - opens in a new tab](https://v17.material.angular.io/components/list/api)
