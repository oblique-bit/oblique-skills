# Card

## Purpose

The Card component is a visual container for related content and actions.

## Usage rules

Use it:
- Use it to enrich a simple selection (e.g., link or checkbox) with more content. An image or a description will provide more context, accelerate the user's decision, and make the layout appear organized.
- Use it as a container for static content (title, subtitle, image) or actions/multiple buttons.

Do not use it:
- Do not use it if content should be read in a specific order or needs a visual hierarchy.

General:
- Use multiple cards on a page: Let the user quickly scan, compare, and select.
- Use a single card on a page: Make a content group stand out from the rest of the page (e.g., as a teaser to another page).
- Using the same card configuration throughout the page will provide a consistent card height and improve scannability.
- Maintain a consistent content structure for the login cards and similar repetitive card types across all applications.

## How to use

This is only a redesign of the Angular Material "Card" component.

The API definition is available on the Angular Material site: [Card - opens in a new tab](https://v17.material.angular.io/components/card/api)
