# Tooltip

## Purpose

Tooltips explain UI elements by displaying labels or messages when users hover over, focus on, or tap an element.

## Usage rules

Use it:
- Use it to provide short explanations.
- Use it to explain icons.
- Use it to explain buttons or links when their labels do not provide enough information.
- Use it to describe differences between similar elements.

Do not use it:
- Do not use it for critical information. They disappear quickly and are not available on touch devices. If information is vital, it is better to present it directly on the page near the related element.
- Do not use it too frequently. It can be distracting for users.
- Do not use it to display extensive content, e.g., many long sentences. For this, consider using the components [Popover](/components/popover), [Dialog](/components/dialog), [Off-Canvas](/helpers/off-canvas), or even creating a new page.

## How to use

This is only a redesign of the Angular Material "Tooltip" component.

The API definition is available on the Angular Material site: [Tooltip - opens in a new tab](https://v17.material.angular.io/components/tooltip/api)

## Additional info

## Manual Control (optional)

Consider manually showing a tooltip in the following cases:

- First-Time Onboarding: guide new users through unfamiliar features.

- Highlighting New Features: Introduce recent updates.

- Contextual Assistance: Offer help if a user seems to be struggling.
