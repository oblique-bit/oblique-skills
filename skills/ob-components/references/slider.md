# Slider

## Purpose

The Slider component allows users to select a value from a range &ndash; via mouse, touch, or keyboard.

## Usage rules

Use it:
- Use it when users need to adjust a value within a range, such as volume, brightness, or zoom level.
- Use it when seeing the effect of changes in real-time is beneficial, such as in color adjustment or filtering content.

Do not use it:
- Do not use it for large ranges where selecting a specific value is cumbersome.
- Do not use it when precise input is required (e.g., monetary amounts or specific measurements). Instead, consider using standard [form](components/form) controls, such as the input field.

General:
- Use the "Thumb Label" option to offer immediate feedback by displaying the current value, enhancing precision and interaction.
- If precise input is required and you still want to use the slider, advise users that they can fine-tune the selection using the keyboard's arrow keys.

## How to use

This is only a redesign of the Angular Material "Slider" component.

The API definition is available on the Angular Material site: [Slider - opens in a new tab](https://v17.material.angular.io/components/slider/api)
