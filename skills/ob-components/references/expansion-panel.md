# Expansion panel

## Purpose

The Expansion panel component allows users to expand and collapse a section of content. Expansion Panels are typically used to display additional information about a topic.

## Usage rules

Use it:
- Use it to organize information in a logical manner.
- Use it to improve the scannability and minimize scrolling.
- Use it in the "Default" style variant (visually separated) when a clear visual distinction between expanded and collapsed panels is needed, aiding user focus, particularly in scenarios with lengthy content within each panel.
- Use it in the "Flat" style variant (visually connected) when prioritizing the maximization of screen space, allowing users to view multiple panels simultaneously without excessive scrolling. This style is especially suitable for interfaces with shorter content within each panel and limited screen space.

Do not use it:
- Do not use it if the user needs all the content at once or to read continuously.
- Do not use it if there is little content on the page.
- Do not use it to display too much content, as this can make it difficult to read.
- Do not use it when an alternative component is a better fit for organizing your content (see Related).

## How to use

This is only a redesign of the Angular Material "Expansion Panel" component.

The API definition is available on the Angular Material site: [Expansion Panel - opens in a new tab](https://v17.material.angular.io/components/expansion/api)
