# Slide toggle

## Purpose

The Slide toggle component allows users to choose between two options by toggling. It always provides a default value.

## Usage rules

Use it:
- Use it to offer users a quick and intuitive way to toggle between two options.
- Use it to provide users with immediate feedback on the state change associated with the toggle.
- Use it when saving screen space and maintaining a clean design is a priority.

Do not use it:
- Do not use it when there is no meaningful default value.
- Do not use it when descriptive labels for each option are needed. Instead, consider Radio Buttons or Checkboxes.
- Do not use it in long forms that require users to click a Submit button. Not knowing if toggling instantly takes effect might confuse users.

## How to use

This is only a redesign of the Angular Material "Slide toggle" component.

The API definition is available on the Angular Material site: [Slide toggle - opens in a new tab](https://v17.material.angular.io/components/slide-toggle/api)
