# Tabs

## Purpose

The Tab component allows users to navigate between multiple content sections within a single interface.

## Usage rules

Use it:
- Use it when organizing related content.
- Use it when guiding users through task flows.
- Use it when limited screen space is a concern.
- Use it when employing progressive disclosure is beneficial.

Do not use it:
- Do not use it when you have a single or linear piece of content.
- Do not use it when screen space for tabs is insufficient.
- Do not use it when content within tabs is highly inconsistent.
- Do not use it when the design is primarily for small mobile screens.

General:
- Ensure the labels are understandable and short.
- Labels can be used alone or combined with an icon. If you include icons, ensure each tab features a meaningful icon. We advise against using icons without accompanying labels due to usability considerations.

## How to use

This is only a redesign of the Angular Material "Tabs" component.

The API definition is available on the Angular Material site: [Tabs - opens in a new tab](https://v17.material.angular.io/components/tabs/api)
