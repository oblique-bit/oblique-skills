# Helper Migration

Migration notes for Oblique 15 to 16. Oblique 16 is the active release and
Oblique 15 is in maintenance. Updates must move through each major version.

## Upgrade procedure

1. Check `package.json` for the installed Angular and Oblique versions.
2. Run the next major update with the Oblique CLI:

   ```shell
   npx @oblique/cli@16 update
   ```

3. Review the schematic diff and the published [Oblique changelog](https://github.com/oblique-bit/oblique/blob/master/projects/oblique/CHANGELOG.md).
4. Run lint, tests, and the application. Keep unrelated changes separate.

The schematics handle several renames and configuration changes. Verify every
generated change before committing it.

## Configuration and language

### Language URL configuration

The `hasLanguageInUrl` boolean is replaced by a language configuration object.
Update code that provides or reads the old boolean, then verify language-aware
routes and navigation.

### Master layout locale configuration

`ObMasterLayoutConfig.locale` is removed. Configure locales through the
`translate.locales` option of `provideObliqueConfiguration`.

The `languages` property inside `translate.locales` was already ignored and is
removed. Delete it rather than replacing it.

### Dates and times

- `datetime` formatting is removed. Use `shortDate` and `mediumTime`.
- `ObDatePipe.format` accepts date formats only. Use its `timeFormat` option
  for time formatting.
- `ObDateComponent.format` follows the same split.
- The date adapter uses Swiss formatting by default. Provide a custom adapter
  after `provideObliqueConfiguration` when the application needs another
  format.

## Helpers with breaking changes

### Error messages

`ObErrorMessagesService` is removed without replacement. Use
`ObErrorMessagesDirective` with `mat-error` and the current
[error messages reference](../error-messages.md).

### Unsaved changes

`ObUnsavedChangesService.isActive` and the directive's `id` and `isActive`
inputs are signals. TypeScript code must read signal values with `isActive()`
and update signal inputs using the current Angular binding style.

### Selectable

Selectable state moved to signals. `selected$`, `mode$`, and `disabled$`
observables are removed or replaced by signal state. Read the current
[selectable reference](../selectable.md) before changing direct subscriptions.

### Schema validation

Schema validation is imported from `@oblique/oblique/schema-validation`.
`ObliqueModule` and `ObliqueTestingModule` no longer include it. `ajv` and
`ajv-formats` are no longer installed explicitly by Oblique.

## Banner and HTTP behavior

`OB_BANNER` is deprecated. Prefer the `banner` property in
`provideObliqueConfiguration`, and provide it after the main Oblique
configuration.

The HTTP interceptor changelog has no comparable 15 to 16 API removal. Use the
current [HTTP interceptor reference](../http-interceptor.md) and check the
schematic diff before changing interceptor registration.

## New helper behavior

Global events add a `navigate` event in Oblique 16. Use it when application
code needs to observe navigation through the Oblique event service.

## Verification checklist

- [ ] `hasLanguageInUrl` and old locale configuration are gone.
- [ ] Date and time formatting use the split APIs.
- [ ] No code calls `ObErrorMessagesService`.
- [ ] Signal-backed helper state is read and bound correctly.
- [ ] Schema validation imports and dependencies are correct.
- [ ] Lint, tests, and a production build pass.
