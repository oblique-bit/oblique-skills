# Translate params

## Import

`import {ObTranslateParamsModule} from '@oblique/oblique';`

## How to use

This pipes allows to translate the parameters of the `translate` pipe.

### Pipes

#### ObTranslateParamsPipe

This pipes allows to translate the parameters of the `translate` pipe.

Selector
`obTranslateParams`

Parameters

`value: string`
The translation key to be translated. A corresponding entry in the translation files is expected

`params?: any`
The parameters to be translated. An object with keys matching entries in the translation files is expected
